# School Management System - Zambia

Built by Leonard - Aspiring MS MIS Student at University at Buffalo

A system for Zambian schools to manage Students, Fees, Grades and Attendance.

## Features
- Login System (Admin)
- Dashboard with Total Students & Fees
- Add & View Students
- Record & Track Fee Payments

## Tech Used
PHP, MySQL, HTML, XAMPP

## How To Run
1. Create database school_db in phpMyAdmin
2. Import tables
3. Run on localhost/school-management-system
4. Login: admin / admin123
