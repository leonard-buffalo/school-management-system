# School Management System

A web-based School Management System built to help Zambian schools manage students, fees, grades, and attendance in one place.

Built by Leonard Buffalo — Lusaka, Zambia

## Features

- **User Login System** - Secure login for school staff
- **Dashboard** - Overview of the whole school
- **Student Management** - Add and view students, grades, and contact info
- **Fees Management** - Track fee payments, amounts, and payment dates
- **Grades Management** - Record student marks by subject
- **Attendance Management** - Mark students Present, Absent, or Late

## Technologies Used

- PHP
- MySQL
- HTML / CSS
- XAMPP / phpMyAdmin
- Git & GitHub

## How To Run This Project

1. Install XAMPP
2. Copy this folder to `htdocs/school-management-system`
3. Start Apache and MySQL in XAMPP
4. Create database `school_db` in phpMyAdmin
5. Import tables: students, fees, grades, attendance, users
6. Open in browser: `localhost/school-management-system`

## Why I Built This

In many schools in Zambia, student records are still kept on paper. This causes lost records, delayed fee tracking, and difficulty in monitoring student performance. I built this system to provide a simple, affordable digital solution for schools in my community.
